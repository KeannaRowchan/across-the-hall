# Sample data

**Every person, lab, project and ask in here is fictional.** These are invented
names used to demonstrate the site and to give a forking department something to
copy the shape of. They are not real colleagues and must never be presented as
real people.

The live site does not read this folder. To use one as a template, copy the file
into the matching folder under `data/` and edit it — the filename must match the
record's `id`.

```
examples/sample-data/people/p-kovacs.json  ->  data/people/p-yourname.json
```

`data/people/p-kovacs.json` shows every available field, including the optional
ones most profiles leave out.
